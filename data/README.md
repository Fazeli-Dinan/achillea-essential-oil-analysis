# Data Description

This folder contains the raw data files for the Achillea essential oil analysis.

| File | Description |
| :--- | :--- |
| `A_biebersteinii.csv` | Country records and essential oil compounds for *A. biebersteinii* |
| `A_millefolium.csv` | Country records and essential oil compounds for *A. millefolium* |
| `A_nobilis.csv` | Country records and essential oil compounds for *A. nobilis* |
| `Achillea_insecticidal.csv` | LC50 values against mosquito larvae |

Full data description will be added after Zenodo archiving.
